# Real-Time Ferry Ticket Sales & Redemption Analytics

## Project Overview
This project analyses Toronto Island Park ferry ticket sales and redemptions to identify trends, understand customer activity, and discover patterns in ticket usage.

## Objectives
- Analyse overall ticket sales and redemptions.
- Identify monthly and yearly sales trends.
- Understand hourly ticket activity.
- Compare weekday and weekend performance.
- Calculate ticket redemption rates.
- Identify peak sales days and unusual activity.

## Dataset
The dataset contains ferry ticket transaction records with the following columns:
- `_id`
- `Timestamp`
- `Sales Count`
- `Redemption Count`
